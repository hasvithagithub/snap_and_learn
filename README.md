# Snap & Learn AI 🚀

Snap & Learn AI is a pocket-sized educational companion designed to make learning interactive, fun, and fast. Using the power of the Gemini AI API, it transforms images, PDFs, and text into simplified explanations, summaries, and quizzes.

## ✨ Features

- **AR Teacher**: Upload a photo or PDF of any object or text, and get a dual-style explanation (Kid mode for simplicity, Expert mode for depth).
- **SnapNotes**: Quickly summarize long notes or documents into concise, actionable bullet points.
- **Quiz Me**: Instantly generate multiple-choice quizzes from your study material to test your knowledge.
- **Gen Z Mode**: Keep it light with AI-generated memes and fun facts about your content.
- **Games Playground**: Take a brain break with classic Tic-Tac-Toe and Memory Match games.
- **Dark Mode**: A sleek, premium interface that's easy on the eyes, day or night.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla JavaScript
- **Styling**: Tailwind CSS (CDN), Custom CSS for Glassmorphism effects
- **Icons**: Lucide Icons
- **AI Engine**: Google Gemini Pro / Pro Vision API
- **Document Parsing**: PDF.js for PDF support

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/hasvithagithub/snap_and_learn.git
   ```
2. **Setup API Key**:
   - Open `config.js`.
   - Add your Gemini API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Alternatively, use the **Settings** gear icon within the app to save your key locally in the browser.
3. **Run**:
   - Simply open `main.html` in any modern web browser.
